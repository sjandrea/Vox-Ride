VoxPilot er installert

  1. Start Logic Pro.
  2. Legg VoxPilot som første insert på vokalsporet: Audio Units → SB Audio → VoxPilot.
  3. Still Vocal Detect like over pust/støy, og Target der vokalen skal ligge.

Ser du ikke pluginen? Gå til Logic Pro → Innstillinger → Plug-in-behandling og velg Tilbakestill og skann utvalg på nytt.
